# awfi

تطبيق أندرويد لأدوات شبكات الواي فاي. مجاني بالكامل، بلا اشتراكات ولا إعلانات ولا حسابات، ولا يرسل أي بيانات إلى أي خادم (اختبار السرعة وحده يتصل بخوادم Cloudflare العامة).

مشروع أصلي كُتب من الصفر، ولا يحتوي أي كود أو صور من تطبيقات أخرى.

## الأدوات
- الرئيسية: الشبكة المتصلة، الإشارة، سرعة الربط، العناوين
- محلل الواي فاي: رسم القنوات، الأمان، أفضل قناة
- اختبار السرعة: تنزيل، رفع، Ping، Jitter
- أجهزة الشبكة: فحص الأجهزة المتصلة
- فحص المنافذ
- Ping وTraceroute وDNS Lookup وWake-on-LAN
- خريطة قوة الإشارة (قراءات حقيقية تسجلها بنفسك)
- استهلاك البيانات لكل تطبيق (يحتاج إذن "الوصول إلى بيانات الاستخدام")
- حماية الشبكة: فحص التشفير وWPS ومنافذ الراوتر، وتعليم الأجهزة المعروفة
- التشخيص: يفسر سبب البطء بقواعد محلية

## الحصول على awfi.apk

### الطريقة 1: GitHub (بدون تثبيت أي شيء)
1. أنشئ مستودعا جديدا على github.com.
2. ارفع كل محتويات هذا المجلد إليه، بما فيها المجلد المخفي `.github`.
3. افتح تبويب **Actions** وانتظر انتهاء "Build awfi.apk" (نحو 4 دقائق).
4. نزّل `awfi.apk` من صفحة **Releases** في المستودع.

### الطريقة 2: Android Studio
1. افتح هذا المجلد في Android Studio.
2. اختر Build ثم Build APK(s).
3. غيّر اسم الملف الناتج `app-debug.apk` إلى `awfi.apk`.

## التثبيت
انسخ الملف إلى الهاتف وافتحه، وفعّل "التثبيت من مصادر غير معروفة" عند الطلب.

## ملاحظات
- لإظهار اسم الشبكة ونتائج الفحص: امنح إذن الموقع وشغّل خدمة الموقع (GPS).
- أندرويد 10 فما فوق يمنع قراءة عناوين MAC، لذلك قد تظهر عناوين IP فقط في قائمة الأجهزة.
- Traceroute وPing يعتمدان على ICMP، وبعض الشبكات تحجبه.
- أندرويد 7 فأقل غير مدعوم (الحد الأدنى أندرويد 8).
